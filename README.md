# hxwl-12 心理咨询会谈复核台

督导会后的会谈复核工作台：咨询师登记会谈摘要、风险等级、下一步计划与归档期限；高风险或教学个案进入督导复核，意见逐条处理完毕才能归档，修改内容另存新版本；咨询师转组时未结意见随案交接。

## 技术栈

React + Vite + TypeScript + CSS（无后端，数据保存在浏览器本机）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 业务规则

- **会谈登记**：摘要、风险等级（稳定 / 关注 / 高风险）、是否教学个案、下一步计划、归档期限；编辑中内容自动存入本机草稿，重开页面继续。
- **督导复核**：高风险或教学个案自动进入复核队列。督导可提出分类意见并设定处理期限；咨询师逐条填写处理说明，督导可退回。意见未全部处理、督导未确认通过前不能归档。
- **版本管理**：首次提交生成 v1，之后每次修改另存新版本并记录修改原因与字段级改动；归档动作归档当前版本，历史版本不可覆盖，支持撤回归档。
- **转组交接**：负责人可把个案转交给其他咨询师，未结意见随案移交，接手人能看到原督导意见、提出人和剩余处理时间；交接全程留痕。
- **分开维护的数据**：个案台账（`hxwl12.cases`）、复核记录（`hxwl12.reviews`）、归档版本（`hxwl12.versions`）、本机保存（`hxwl12.local`，角色/选中项/草稿）四个 localStorage 命名空间相互独立，可在侧栏分别清空或一键重置演示数据。

## 数据模型

| 类型 | 文件 | 说明 |
| --- | --- | --- |
| `CounselorCase` / `ReviewOpinion` / `CaseVersion` / `LocalState` | `src/types.ts` | 个案、意见、版本与本机状态 |
| 存储与种子数据 | `src/storage.ts` | 四个命名空间、持久化 Hook、时间工具、演示数据 |
| 工作台界面 | `src/App.tsx` | 列表、登记、复核、版本、交接四个标签页 |
